# nightmare-writeups

A collection of my notes, disassembled binaries, and small programs as I learn low-level programming, reverse engineering, and binary exploitation on Linux using [Nightmare](https://guyinatuxedo.github.io/).

Currently i'm a beginner at Low Level stuff + English is not my first language, so sorry if you end up seeing horrible english grammar and vocabulary. 
Explaining low level stuff is difficult itself, so it becomes quite complex to do so using a language that isn't your native one, but I'm trying my best to improve.

## My Goals
- Understand x86/x86_64 assembly syntax (Intel and AT&T)
- Learn how C code translates into machine instructions
- Practice using Linux debugging and disassembly tools
- Learn binary exploitation techniques

## Tools Used
- **Compiler:** `gcc`
- **Disassembler / Debugger:** `gdb`, `objdump`
- **OS:** Linux (WSL)

## Repository Structure
- `/x-name` - Dedicated folders containing notes and writeups for specific Nightmare challenges ('x' indicates the number of the nightmare section while 'name' indicates the challenge module name).
